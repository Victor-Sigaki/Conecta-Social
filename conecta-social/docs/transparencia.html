Transparência e privacidade

Conecta Social é uma organização fictícia usada em um projeto acadêmico de Desenvolvimento Front-End para Web. Projetos, números, metas e atividades apresentados são ilustrativos e não representam resultados de uma ONG real.

Doações

O site não recebe pagamentos, não processa transações financeiras e não solicita dados bancários. A área de doações apenas simula a seleção de um valor.

Cadastro e armazenamento

O formulário demonstra validação HTML5, máscaras de entrada e armazenamento no LocalStorage do navegador. Os dados não são enviados a um servidor. Para testes, utilize dados fictícios e apague os registros ao terminar.

Segurança

Esta versão é um projeto estático de front-end. Não implementa autenticação, processamento server-side, banco de dados, envio de e-mails ou certificados reais. Uma versão de produção precisaria de HTTPS, validação no servidor, controle de acesso e política de retenção de dados.

Acessibilidade

O projeto busca oferecer navegação por teclado, rótulos associados aos campos, mensagens de status, estrutura semântica, foco visível e contraste legível. Recomenda-se validar com ferramentas automáticas e testes manuais com leitores de tela.
