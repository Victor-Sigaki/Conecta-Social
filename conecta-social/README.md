# Conecta Social - Site para uma ONG

Esse projeto foi desenvolvido para a disciplina de Desenvolvimento Front-End para Web. A ideia é criar um site para uma ONG fictícia, mostrando seus projetos sociais e algumas formas de ajudar.

O site permite conhecer a ONG, visualizar projetos, simular doações e preencher um formulário de cadastro.

**Importante:** Esse projeto é apenas um protótipo acadêmico. Não possui banco de dados, login, envio de e-mails ou pagamentos reais. As informações e doações são apenas exemplos. Utilize dados fictícios nos testes.

## Páginas do projeto

- `index.html`: página inicial com informações sobre a ONG, sua missão, seus valores, projetos e contato.
- `projetos.html`: apresenta os projetos sociais, opções de voluntariado e simulação de doações.
- `cadastro.html`: formulário para preencher dados fictícios, com máscaras e validação dos campos.
- `docs/transparencia.html`: explica algumas informações sobre privacidade e as limitações do site.

## Tecnologias utilizadas

- **HTML5:** usado para criar a estrutura das páginas, títulos, menus, imagens, links e formulários.
- **CSS3:** usado para definir as cores, os estilos e adaptar o site para celulares e computadores.
- **JavaScript:** usado para fazer o menu funcionar, validar os formulários, formatar CPF, telefone e CEP e simular doações.
- **Acessibilidade:** foram adicionados recursos para facilitar a navegação pelo teclado e a utilização do site.
- **Git e GitHub:** utilizados para organizar o projeto e permitir o compartilhamento dos arquivos.

## Como executar o projeto

1. Extraia o arquivo ZIP do projeto.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Navegue pelas páginas usando o menu.
5. Teste os formulários utilizando dados fictícios.

## Imagens

As imagens do projeto estão na pasta `assets/img/`. Foram utilizados arquivos nos formatos SVG, PNG e WebP. Algumas imagens possuem carregamento adiado para ajudar no desempenho do site.
